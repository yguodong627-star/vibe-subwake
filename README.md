# 订醒 SubWake

本地订阅审计台账。打开网页即用，零配置，数据只存在你的浏览器。

## 用户

同时订了流媒体、AI 工具、云盘、健身会员的都市职场人 / 产品经理 / 独立开发者（常见 5–15 个订阅，含海外 SaaS）。

## 场景

- 发薪日或周末做一次「订阅审计」
- 开通免费试用前先登记，避免静默转正
- 每季度打开看一眼「下个月会扣多少」

## 问题

自动续费和试用转正会静默扣款。很多人答不出「我每月订阅一共多少钱、下周有没有扣款」，钱就这样悄悄流走。

银行 App 聚合不了 ChatGPT / Notion / Midjourney 等海外订阅；Excel 难看且难坚持；海外理财 App 要绑卡且偏美国市场。订醒只做一件事：把订阅记清楚、把即将扣款亮出来。

## 怎么用

1. 打开页面，首次会带 5 条「示例」订阅，可直接改或点「清空示例」
2. 点「添加」录入名称、金额、币种、周期、下次扣款日、分类等
3. 看板看本月折算花费、年化、7 天内扣款、试用将到期
4. 勾选订阅，用「如果取消这些」估算能省多少月费
5. 右上角可导出 / 导入 JSON 备份

折算规则：周 × 4.345、月 × 1、季 ÷ 3、年 ÷ 12；USD 按 1 ≈ 7.2 CNY 仅用于汇总估算（标明「估算」），列表仍显示录入币种。

## 本地隐私

- 无账号、无 API、不上云
- 全部数据在 `localStorage`
- 可随时导出 JSON 备份到本机

## 市场参考

- Citizens Advice 估计英国一年 unused subscriptions 约 £688M
- Westpac 调查：澳人 unused / duplicate 最高约 $600/年，38% 忘取消试用
- Forrester：不到一半美国人清楚自己全部订阅
- Product Hunt 上 Subo / Subsight / PayClear / Barnacle / SubTrack 等本地隐私向订阅追踪器反复出现，说明需求真实
